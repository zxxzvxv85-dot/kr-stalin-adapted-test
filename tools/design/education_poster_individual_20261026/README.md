# 教育海报逐张图生图（2026-10-26）

用户要求每张海报分别处理，不能套统一空纸背景。本目录为现有51项宣传海报逐项保存内置`image_gen`的独立编辑结果。每次调用只以该项原JPEG为编辑目标，保留该海报的主题、版式、方向与主要画面，分别处理纸张起伏、折痕、薄边、局部翘角和接触阴影。没有使用CLI/API后备，工具未报告底层模型名称。

- `sources/ID.source.png`：该海报的完整透明AI处理源，未合成木板；原JPEG仍在`education_system_20261024/posters/`，不覆盖。
- `ID.json`：对应原图、实际生成文件来源、工具和完整最终提示词。一项一调用，不以一张通用纸或拼图替代51张。
- `manifest.json`：每张原图、AI源、提示词元数据的SHA-256，源尺寸、透明度、实际纸张裁切范围及比例记录。元数据JSON由定向.gitattributes固定LF换行以保证跨电脑SHA一致。源图像素尺寸不同；游戏封装统一为160×205透明帧，等比容纳于154×199，保留各自横竖比例。

材质编辑结果用于游戏界面，原始档案仍单独保存。AI结果已经在游戏尺寸与原图逐对检查构图、人物、标题区域和方向；不将这些处理版当作原始海报扫描件。

`python tools/education_poster_individual_art.py --record`在全部51项到齐后登记输入清单；默认只读校验。`python tools/education_workbench_art.py --write`打包七份53帧PNG，前两帧逐像素保留原空闲/锁定胶痕。无需重新调用图生成即可再现打包。

七级磨损门槛为0/12.5/25/37.5/50/62.5/75%。每张自己的处理源作为初始纸边、折痕和印刷；后期叠加原版累计缺口alpha及轻微褪色/去饱和。25/50/75主档之间增加过渡层，缺口单调增加，不恢复破掉的角，也不在切换分类时重新开始。后期变化不贴统一空白纸、不导入别的海报图案。所有活动条形进度控件已删除，只显示海报名称和倒计时，三项教育指标条保留。

验证入口为`python tools/validate.py --group education structure`。原字体布局校样与逐对对照图在忽略的`output/education_poster_individual_20261026/`；这些是校样，不是游戏截图。

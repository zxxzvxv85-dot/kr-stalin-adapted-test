网页版测试包：社革党十一国策图标

最简单的用法：
1. 把整个 ZIP 上传给网页版。
2. 对它说：“请先解压附件，读取 PROMPT_COPY_TO_WEB.txt，然后严格按里面的要求编辑 01 号模板并返回 PNG。”
3. 如果网页版不能读取 ZIP，就在本地解压，上传 01 至 08 的八张 PNG，再粘贴 PROMPT_COPY_TO_WEB.txt 全文。
4. 如果网页版限制上传数量，优先上传 01、02、03、05、06、08；04 是社革党单框结构补充，07 是党代会和民兵构图补充。

文件用途：
- 01_EDIT_TARGET_exact_100px_slots_3344x1888.png：唯一允许编辑的几何模板。整张画布 3344x1888，内部 11 个圆槽均为 100x100，排列为 4+4+3。
- 02_SUBJECT_REFERENCE_current_11_icons.png：现有 11 个图标的主题和顺序参考。只继承含义，不继承旧底框、锐度和细节错误。
- 03_STYLE_REFERENCE_official_KR_icons.png：官方 KR 总体图面、材质、明暗和缩略图密度参考。
- 04_FRAME_STRUCTURE_REFERENCE_RUS_ESER.png：官方俄国激进社会主义框体结构参考，用来理解框沿遮挡和金属质感，不得逐像素复制。
- 05_OFFICIAL_KR_RUSSIAN_ESER_AND_SOCIALIST_REFERENCE_SHEET.png：俄国社革党、社会主义与农业题材参考。
- 06_OFFICIAL_KR_LAND_RURAL_AND_COOPERATIVE_REFERENCE_SHEET.png：土地、农村、合作社、村社和农民题材参考。
- 07_OFFICIAL_KR_PARTY_DEMOCRACY_AND_MILITIA_REFERENCE_SHEET.png：党代会、革命民主、协商与民兵题材参考。
- 08_OFFICIAL_KR_ROUNDED_FRAME_AND_MATERIAL_REFERENCE_SHEET.png：圆润框体、金属明暗、磨损和前景框沿参考。
- REFERENCE_INDEX.txt：四张官方参考板的图标顺序与允许参考范围。
- PROMPT_COPY_TO_WEB.txt：直接交给网页版执行的完整英文提示词。

关键要求：
- 必须返回 PNG，不要 JPEG 或 WebP。
- 完整图标连同底框都必须装在各自 100x100 槽位里，不能把“总画布尺寸”误解成“单个图标尺寸”。
- 11 个底框必须属于同一个社革党框族：圆润铜银框、麦穗尖、土地纹样、少量暗红和深绿珐琅，不能照搬布尔什维克的硬钢齿轮框。
- 第 1 个是重要的路线起点，第 11 个是农业社会主义终点；可以略加强装饰，但轮廓、材质和尺寸仍必须属于同一家族。
- 参考图只能影响风格、构图、材质和细节密度，禁止直接拼贴外国国旗、国徽、文字或现成边框。
- 把网页版返回的原始 PNG 发回来，不要截图，也不要经过聊天软件压缩。

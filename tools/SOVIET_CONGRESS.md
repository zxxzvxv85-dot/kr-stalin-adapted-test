# 苏维埃与工会代表大会：初版席位展示

只开发测试目录。首次点“查看代表大会（测试）”初始化；测试入口分类不挂GUI，初始化成功后才显示大会分类，随后原生展开/折叠。
入口暂向原始国家为 RUS 的人类玩家开放，不依赖新政治线尚未实装的派系国策。
本版没有投票、选举、席位争夺或战役奖励。

## 维护入口

- `tools/generate_soviet_congress.py`：唯一维护源，包含派系/演示数据、几何布局、脚本与本地化。
- 默认及 `--check` 只读；`--write` 更新13个拥有的运行文件；`--preview` 另输出主/子视图及原生尺寸布局图。
- `tools/test_soviet_congress.py`：生成效果执行、800席分布、重复入口、无效总数、逐项显隐、坐标属性、真实字体宽度及界面绑定。
- `tools/hoi4_bitmap_fonts.py`：只读解析已安装KR汉化字体、原游戏位图字体回退链和字符advance；没有复制字体入模组。预览使用原字形，不能模拟最终引擎着色及阴影。
- `output/soviet_congress/代表大会子派系预览_原生尺寸.png` 分别为500×824/500×1360布局校样，不是游戏截图。

## 状态接口

- `RUS_congress_prepare_demo`：以 `RUS_congress_demo_initialized` 旗标保护，仅首次设置演示席位。
- `RUS_congress_bolsheviks_seats / unions_seats / labour_seats / sr_seats / democrats_seats`：五个持久国家变量，整数且总和必须是800。
- `RUS_congress_refresh_display`：检查总和800、每项0–800、四组子派合计分别等于父派、公民派合计等于两个来源且不透支任一来源，再重建 `RUS_congress_seats` 数组，计算各 `*_percent`，递增 `RUS_congress_revision`；无效输入不发布新显示。
- 公民派来源变量：`RUS_congress_citizens_from_populists / citizens_from_democrats`，默认各25；公民派总数保存在`RUS_congress_sr_citizens_seats`。展开颜色数组时，两来源父派扣除公民份额后的剩余席位加公民合计，只占800席一次；主/中层小计仍保留原总数。
- GUI的800个固定位置读取颜色数组帧1–20。位置按角度排序，各派形成连续区域。`dirty`、数组帧与数值本地化均显式绑定 `RUS.RUS_congress_*`，依照KR菲律宾界面的国家作用域写法，无每日钩子。
- 原生scripted_gui属性不提供根窗口height；用互斥的`RUS_congress_category / RUS_congress_children_category`分别绑定824/1360px真实根窗口。两类共用标题/数据/按钮语义，初始化后仅一类可见；对应scripted_gui有同样显隐门槛，避免隐藏长根仍占滚动高度。主窗只含5行父派，长窗含20行，各有静态位置；不再维护多余row_y/icon_y变量。长窗60个子控件仍独立_visible，避免依赖隐藏嵌套图例容器。
- 后续事件改变席位时应在同一效果内先转移席位、保持整数及总和，再调用 refresh。不要再次调用初始化来覆盖玩家已有分布。

- 已参考 KR `common/scripted_guis/_documentation.md`、`PHI scripted_gui (Philippines).txt` 的数组取帧、`00_mobilisation_effects.txt` 的 `while_loop_effect`。
- 决议入口参照现有 `RUS_doudizhu_decisions.txt` 与分类；y属性与逐项显隐参照KR原生scripted_gui文档和已有界面。

## 原生运行问题证据与回归

用户2026-10-23截图显示缺字、0席、同色与两种图例重叠，已确认完全重启并点击过测试决议。本机error.log有22条 `No font with name hoi_14mbs`。字体缺失已确定；同时修正显式国家读取、初次构建门槛、姓名查找与头像非懒加载别名，避免只修问号而保留数据和提示问题。

前轮截图确认颜色、席数和头像姓名已经恢复，但双栏图例依旧重叠。本机game.log显示切换在revision20–29之间交替生效；因此按钮和旗标已执行，原先仅测试父容器条件不足以覆盖实际叶控件显示。现已删除双图例容器，改为唯一父派列表、独立子控件条件、一个按钮及两套y坐标。预览使用原字形/advance且逐项检查可见矩形；不再用Pillow替代字体和容器条件测试推断引擎验收。

专项测试保留初始化完整链、显式国家读取、12名人物及文字图标；追加六次真实单按钮if/else、两态坐标/叶显隐、数字极值字宽、图片源SHA及比例。每次动作仅记录一条日志。新的1360高度在实际游戏内的滚动、字体与显隐刷新尚需完全重启新局确认；本轮未启动或操作游戏。

最新实测截图暴露536px画布超出原生502px槽宽，上一轮只校验自设画布不足以发现裁切。当前专项测试直接读取原生decision_grid槽宽，并校验34px占比余量、三个缩进深度、20项关系图边、跨派不重复计席与来源边界、标题到各67px头像的80px间隔。用户随后要求主要派系模式收短空白，已改为两个真正不同高度且互斥的分类根窗口，测试真实按钮在两类之间切换、只有一个可见、主窗末行以下仅26px；实际引擎行高/滚动及分类即时替换仍待重启验收。

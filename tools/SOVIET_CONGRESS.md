# 苏维埃与工会代表大会：初版席位展示

只开发测试目录。首次点“查看代表大会（测试）”初始化；测试入口分类不挂GUI，初始化成功后才显示大会分类，随后原生展开/折叠。
入口暂向原始国家为 RUS 的人类玩家开放，不依赖新政治线尚未实装的派系国策。
本版没有投票、选举、席位争夺或战役奖励。

## 维护入口

- `tools/generate_soviet_congress.py`：唯一维护源，包含派系/演示数据、几何布局、脚本与本地化。
- 默认及 `--check` 只读；`--write` 更新11个拥有的运行文件；`--preview` 另输出布局图。
- `tools/test_soviet_congress.py`：生成效果执行、800席分布、重复入口、无效总数及界面绑定。
- `output/soviet_congress/代表大会布局预览.png` 是依照运行几何绘制的预览，不是游戏截图。

## 状态接口

- `RUS_congress_prepare_demo`：以 `RUS_congress_demo_initialized` 旗标保护，仅首次设置演示席位。
- `RUS_congress_bolsheviks_seats / unions_seats / labour_seats / sr_seats / democrats_seats`：五个持久国家变量，整数且总和必须是800。
- `RUS_congress_refresh_display`：检查总和800、每项0–800、两组子派合计分别等于父派，再重建 `RUS_congress_seats` 数组，计算各 `*_percent`，递增 `RUS_congress_revision`；无效输入不发布新显示。
- GUI的800个固定位置读取颜色数组帧1–10。位置按角度排序，各派形成连续区域。`dirty`、数组帧与数值本地化均显式绑定 `RUS.RUS_congress_*`，依照KR菲律宾界面的国家作用域写法，无每日钩子。
- 后续事件改变席位时应在同一效果内先转移席位、保持整数及总和，再调用 refresh。不要再次调用初始化来覆盖玩家已有分布。

## 样式与参考

- 536×620，适配现有决议分类的约540px内容宽度。每点一席，上部徽记复用本模组 `GFX_focus_RUS_the_supreme_soviet`，无新插画生成。
- 面板与色点为脚本绘制的几何界面贴图；色点图集60×6、10帧，面板536×620。
- 紧凑文字使用KR简中 `interface/core_chinese.gfx` 已注册的 `Main_14`，禁止恢复不存在的 `hoi_14mbs`。字体检查须读取已安装字体定义，Pillow替代字体预览不能证明游戏内字体可用。
- 已参考 KR `common/scripted_guis/_documentation.md`、`PHI scripted_gui (Philippines).txt` 的数组取帧、`00_mobilisation_effects.txt` 的 `while_loop_effect`。
- 决议入口参照现有 `RUS_doudizhu_decisions.txt` 与分类；图标身份参照KR俄国代表大会的议会主题及本模组既有最高苏维埃徽记。
- 最终引擎内的分类高度、字体、本地化渲染、帧刷新及头像悬浮的原生行高排版需完全重启并用新局验证。

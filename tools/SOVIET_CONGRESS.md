# 苏维埃与工会代表大会：初版席位展示

只开发测试目录。首次点“查看代表大会（测试）”初始化；测试入口分类不挂GUI，初始化成功后才显示大会分类，随后原生展开/折叠。
入口暂向原始国家为 RUS 的人类玩家开放，不依赖新政治线尚未实装的派系国策。
本版没有投票、选举、席位争夺或战役奖励。

## 维护入口

- `tools/generate_soviet_congress.py`：唯一维护源，包含派系/演示数据、几何布局、脚本与本地化。
- 默认及 `--check` 只读；`--write` 更新12个拥有的运行文件；`--preview` 另输出主/子视图及原生尺寸布局图。
- `tools/test_soviet_congress.py`：生成效果执行、800席分布、重复入口、无效总数、逐项显隐、坐标属性、真实字体宽度及界面绑定。
- `tools/hoi4_bitmap_fonts.py`：只读解析已安装KR汉化字体、原游戏位图字体回退链和字符advance；没有复制字体入模组。预览使用原字形，不能模拟最终引擎着色及阴影。
- `output/soviet_congress/代表大会子派系预览_原生尺寸.png` 为536×1080布局校样，不是游戏截图。

## 状态接口

- `RUS_congress_prepare_demo`：以 `RUS_congress_demo_initialized` 旗标保护，仅首次设置演示席位。
- `RUS_congress_bolsheviks_seats / unions_seats / labour_seats / sr_seats / democrats_seats`：五个持久国家变量，整数且总和必须是800。
- `RUS_congress_refresh_display`：检查总和800、每项0–800、两组子派合计分别等于父派，再重建 `RUS_congress_seats` 数组，计算各 `*_percent`，递增 `RUS_congress_revision`；无效输入不发布新显示。
- GUI的800个固定位置读取颜色数组帧1–10。位置按角度排序，各派形成连续区域。`dirty`、数组帧与数值本地化均显式绑定 `RUS.RUS_congress_*`，依照KR菲律宾界面的国家作用域写法，无每日钩子。
- 刷新同时设置每行的 `RUS_congress_<key>_row_y / icon_y`；40个根级控件通过原生y属性读国家变量。只保留一个切换按钮和一套父派控件，20个子派叶控件各有独立 `_visible` 条件，不再依赖隐藏父容器来隐藏整个图例。
- 后续事件改变席位时应在同一效果内先转移席位、保持整数及总和，再调用 refresh。不要再次调用初始化来覆盖玩家已有分布。

## 样式与参考

- 536×1080，适配现有决议分类的约540px内容宽度。上方改为会场模拟全景；下方仍为800个真实数据席点。
- 会场由内置image_gen生成，工具未返回具体模型。完整源1774×887 RGB，等比导出512×256 RGBA，不裁切、不拼贴徽记；完整提示词、来源、SHA及实际验收在 `tools/design/soviet_congress_hall_20261023/`。不声称为真实历史会场复原。用户指出中轴偏移后，内置图生图另存source-symmetric.png，将齿轮浮雕/锤子、讲台、过道对齐画面中央；原图及原始提示词保留。底部两行机制说明按用户要求移除。
- 面板与色点为脚本绘制的几何界面贴图；色点图集60×6、10帧，面板536×1080。
- 主派系 `hoi_18mbs`，子派系及说明 `hoi_16mbs`，标题 `hoi_24header`，均核对KR汉化真实字体及回退字形。三列留出间隔，行距36/32px；测试用实际字宽核对长中文名及0–800席/0–100%边界。禁止恢复不存在的 `hoi_14mbs`。
- 已参考 KR `common/scripted_guis/_documentation.md`、`PHI scripted_gui (Philippines).txt` 的数组取帧、`00_mobilisation_effects.txt` 的 `while_loop_effect`。
- 决议入口参照现有 `RUS_doudizhu_decisions.txt` 与分类；y属性与逐项显隐参照KR原生scripted_gui文档和已有界面。
- 最终引擎内的分类高度、字体、本地化渲染、帧刷新及头像悬浮的原生行高排版需完全重启并用新局验证。

## 原生运行问题证据与回归

用户2026-10-23截图显示缺字、0席、同色与两种图例重叠，已确认完全重启并点击过测试决议。本机error.log有22条 `No font with name hoi_14mbs`。字体缺失已确定；同时修正显式国家读取、初次构建门槛、姓名查找与头像非懒加载别名，避免只修问号而保留数据和提示问题。

第二次截图确认颜色、席数和头像姓名已经恢复，但双栏图例依旧重叠。本机game.log显示切换在revision20–29之间交替生效；因此按钮和旗标已执行，原先仅测试父容器条件不足以覆盖实际叶控件显示。现已删除双图例容器，改为唯一父派列表、20个独立子控件条件、一个按钮及两套y坐标。预览使用原字形/advance且逐项检查可见矩形；不再用Pillow替代字体和容器条件测试推断引擎验收。

专项测试保留初始化完整链、显式国家读取、12名人物及文字图标；追加六次真实单按钮if/else、两态坐标/叶显隐、数字极值字宽、图片源SHA及比例。每次动作仅记录一条日志。新的1080高度在实际游戏内的滚动、字体与显隐刷新尚需完全重启新局确认；本轮未启动或操作游戏。

# 东墙原生转红路线限制

2026-10-29：只处理用户指定的BAT、LIT、BLR、GEO、AZR；乌克兰沿用既有盖特曼结局锁。用户明确保留战后建立社会主义政府的方式。

`generate_ostwall_route_locks.py`从当前KR读取四个同路径完整文件，仅修改五个原生入口：波罗的解体事件`.31`、立陶宛革命决议和成功事件`.210`、白罗斯投向第三国际事件`.42`及战时转向俄罗斯的`.53.a`。白罗斯`.53.b`只在受限制状态下给AI正权重，原其他场景仍为0。其他原生节点逐项AST不变。

一个共享触发器界定五个原TAG的自然政权：已经是社会主义／共产主义政府的国家，以及社会主义宗主国的附属国不受影响。不会每日强行更改政府、党派支持率、领土或宗主国。被允许的战后释放无需依赖新增保存旗标。

波罗的在森林兄弟出现后调用原生镇压胜利事件`.41`，保留其原生收尾、抵抗清理和奖励；原解体事件在受限时不会执行。五个非红色自然政权不能主动进入红色阵营。原生`on_join_faction`用于主动加入；脚本`add_to_faction`使用`on_offer_join_faction`且FROM为受邀国，另有每日检查覆盖旧联盟状态。两个钩子的作用域已参考当前游戏`00_on_actions.txt`的注释。

当前KR的GEO/AZR事件没有直接切换到三种原生社会主义／共产主义执政党的入口，因此不复制、篡改它们的政府事件；它们通过五国共享的主动外交阵营限制覆盖。来源及SHA记录在`design/ostwall_route_locks_inputs_20261029.json`（四个修改源及这两个审核源）。这组来源独立于顾问／ideas生成器的旧KR比较基线；不擅自重录后者。

默认和`--check`只读，显式`--write`生成八个输出。`test_ostwall_route_locks.py`覆盖270种TAG／政府／宗主国／阵营组合、重复收尾、原生入口与非目标内容保留，以及邀请钩子作用域；检查已注册`foreign`组。游戏更新后先审阅六个来源的差异，再决定重建。新开局为验收基线，不追溯已完成的原生政变，也不回滚战后红色政权。
